# ComfyUnreal

Unreal Engine 5.8 plugin that generates images, textures, video, 3D meshes and audio through Comfy (Comfy Router, local ComfyUI, or Comfy Cloud) and imports the results as assets. It also exposes an AI toolset to Epic's Unreal MCP server.

Status: proof of concept. Test project: `D:\UnrealProjects\ComfySandbox`.
